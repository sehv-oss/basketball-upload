# Notice

## Design

The basketball file upload implemented here, from the dropzone that doubles as a backboard to the slingshot shot, the aiming dots, the swish of the net and the upload list, is a design by **Jorge Molina**, published on Figma Community.

- GitHub: [jm-fuster](https://github.com/jm-fuster)
- Figma Community: [@jm_fuster](https://www.figma.com/@jm_fuster)
- Website: [jorgemolinafuster.com](https://jorgemolinafuster.com)

This project is an independent code implementation of that design, made with admiration for the original work. It is not affiliated with or endorsed by the author.

Changes and additions made in this implementation:

- the Web Component and React APIs, and the upload pipeline behind the list;
- the physics of the shot, and keyboard (assisted) shots;
- the dark theme and the theming tokens;
- built-in and custom file types;
- form association, accessibility announcements and reduced motion support.

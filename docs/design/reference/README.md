# Reference design

Screenshots of the prototype this project implements, a design by **Jorge Molina** ([jm-fuster](https://github.com/jm-fuster), [@jm_fuster](https://www.figma.com/@jm_fuster) on Figma Community). See [NOTICE.md](../../../NOTICE.md).

They are the reference for colors, geometry and motion. The site renders the element alone, at the size of these frames, at `?reference` (`pnpm site:dev`, then `/basketball-upload/?reference`), for side-by-side comparisons.

| File                            | Moment                                                      |
| ------------------------------- | ----------------------------------------------------------- |
| `01-aim.png`                    | The card pulled back; the dots show the path of the shot    |
| `02-release.png`                | Just released: the dots already passed disappear            |
| `03-flight-dropzone-active.png` | In the air, over the dropzone, which lights up              |
| `04-rim.png`                    | Going down through the rim, behind its front edge           |
| `05-net.png`                    | Through the net, which stretches                            |
| `06-score-uploading.png`        | Below the net, fading; "+1", the counter and the upload row |
| `07-uploading.png`              | Uploading                                                   |
| `08-uploaded.png`               | Uploaded                                                    |
